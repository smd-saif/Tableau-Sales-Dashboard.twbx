# Tableau Sales Dashboard

## Project Overview

An interactive sales analysis dashboard created using Tableau to analyze sales performance across different categories, sub-categories, and regions.

## Tools Used

* Tableau
* Excel
* Data Visualization

## Analysis

The project analyzes:

* Sales by Region
* Sales by Category
* Sales by Sub-Category
* Sales performance using different measures
* Regional and category-level comparisons

## Files

* `Tableau-Sales-Dashboard.twbx` — Tableau packaged workbook
* `Dashboard.png` — Dashboard preview

## Key Skills Demonstrated

* Data visualization
* Tableau dashboard development
* Filters and interactive analysis
* Category and regional analysis
* Business-oriented data presentation
